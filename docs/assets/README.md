## Production and verification

- Created as editable Excalidraw scenes; SVG previews derived from those scenes and PNG previews rendered from the SVGs.
- SprintAI editorial palette: paper `#FAFAF7`, navy `#1B3C5C`, orange `#F47920`, with supporting navy/orange tints. No logo or third-party illustration assets.
- Sans-serif typography; the preview font stack uses IBM Plex Sans Thai, Sarabun, Thonburi, Arial, and the platform sans-serif fallback. Excalidraw uses its native sans-serif family. Font files are not bundled.
- Both scenes passed the Excalidraw scene validator. Browser text-bound checks found no overflowing labels after correction; both rendered previews were visually inspected for clipping, connector direction, and readable Thai labels.
- The figures describe the intended workflow, not evidence of a completed dashboard build. No image generator was used.
